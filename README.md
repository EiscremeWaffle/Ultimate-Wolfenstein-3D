# Ultimate-Wolfenstein-3D
A personal project compilying all official wolfenstein campains and missions into one big PK3 think DOOM 1+2 on Steam
It's currently still very rough but the Original Game, Spear of Destiny, The Lost Episodes and Original Encounter are all here!
There is also a Marathon Episode stringing all Levels together in a somewhat canonical order.
I also added an extra difficulty which isnt fully done yet tho
Included is a wmc due to a huge part of this project being a collection of all actors weapons and textures for map making accesability!
